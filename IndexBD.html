Funcionamiento de una Base de Datos

Una base de datos es un conjunto organizado de información que permite el almacenamiento, consulta y eliminación de datos de manera eficiente. El ciclo de funcionamiento se estructura en tres partes principales:

  • Una Aplicación que solicita y muestra la información.
  • Un Gestor (DBMS) que interpreta las solicitudes y administra el acceso.
  • La Base de Datos física o virtual donde se aloja la información organizada.

Bases de Datos Relacionales (SQL)

Este enfoque organiza la información en tablas interconectadas mediante llaves primarias y foráneas. Es el modelo adecuado cuando se requiere una estructura definida, integridad estricta de datos y soporte para transacciones seguras (como en sistemas bancarios o escolares).

En el entorno práctico, se utilizan herramientas profesionales como DBeaver para la administración y visualización de gestores relacionales robustos como PostgreSQL, facilitando el manejo eficiente de la información y la construcción de consultas.

PostgreSQL DBeaver MySQL

Bases de Datos No Relacionales (NoSQL)

A diferencia del modelo tradicional, este enfoque almacena información con estructuras flexibles, utilizando documentos JSON, grafos o pares de clave-valor. Su implementación es recomendada cuando la estructura de los datos cambia frecuentemente o se manejan grandes volúmenes de información a alta velocidad.

Análisis de la Persistencia Políglota

Se destaca el concepto de persistencia políglota, el cual demuestra que los sistemas modernos no se limitan a una sola tecnología. Consiste en combinar diversos gestores según sus fortalezas en un mismo proyecto. En una aplicación de comercio electrónico, por ejemplo, se podría utilizar PostgreSQL para transacciones de pagos por su seguridad, MongoDB para el catálogo de productos debido a su flexibilidad, y Redis para almacenar la caché buscando un alto rendimiento.

Dudas y Temas de Interés Futuro

A partir del conocimiento adquirido en los fundamentos, se identifican las siguientes áreas de interés para profundizar a lo largo del curso:

Conexión con el código fuente

Se busca comprender cómo se establece exactamente el "puente" de conexión entre la base de datos y un lenguaje de programación para enviar consultas desde una aplicación real.

Servidores de bases de datos

Existe un fuerte interés por conocer más acerca de los servidores de bases de datos. Se desea aprender cómo se configuran, cómo funcionan a nivel de arquitectura y cuáles son las mejores prácticas para desplegar una base de datos en un entorno de producción real.

Diseño de esquemas

Se desea analizar cuáles son las repercusiones a largo plazo cuando se cometen errores en el diseño inicial de las llaves primarias y foráneas, y qué tan complejo resulta refactorizar una base de datos en producción.
